# 5. RINGKASAN METODOLOGI
# =============================================================================
#
#   Target bersifat ORDINAL (1 Sangat puas ... 4 Sangat tidak puas) dan metrik
#   QWK menghukum kesalahan secara kuadratik. Karena itu target tidak
#   diperlakukan sebagai empat kelas terpisah.
#
#   Alur akhir:
#
#     1. Enam model dasar dilatih dengan validasi silang 5-fold yang identik:
#        LightGBM, CatBoost, XGBoost (klasifikasi), regresi Huber,
#        dekomposisi biner kumulatif, dan MLP.
#
#     2. Probabilitas dari lima model berbasis pohon dirata-ratakan secara
#        sederhana. MLP dikeluarkan karena QWK tunggalnya jauh di bawah yang
#        lain sehingga mengencerkan rata-rata. Keputusan ini ditetapkan
#        di muka, bukan dengan mengambil skor validasi tertinggi.
#
#     3. Probabilitas diubah menjadi nilai harapan E[y] = sum(p_k * k).
#
#     4. E[y] dipotong dengan tiga ambang batas. Ambang diestimasi dengan
#        merata-ratakan hasil optimasi pada puluhan resampel bootstrap dari
#        prediksi out-of-fold — teknik reduksi variansi agar ambang berada di
#        pusat dataran tinggi permukaan QWK, bukan pada puncak derau tunggal.
#
#   Seluruh keputusan diambil dari data latih. Data uji tidak pernah dipakai
#   untuk memilih model, bobot, maupun ambang batas.
#
#   Keputusan paling berdampak adalah langkah 3–4. Mengganti argmax dengan
#   nilai harapan berambang menaikkan QWK jauh lebih besar daripada seluruh
#   pekerjaan pemodelan lainnya digabung — rinciannya pada Bagian 9 dan 10.4
#   notebook.
#
#

# 6. CATATAN REPRODUKSIBILITAS
# =============================================================================
#
#   Seluruh sumber keacakan yang dapat dikendalikan telah dikunci: SEED = 42
#   untuk pembagian fold, FOLD_SEEDS untuk inisialisasi tiap model dasar, dan
#   seed tetap pada seluruh prosedur resampling.
#
#   Satu hal perlu disampaikan terbuka. LightGBM, XGBoost, dan CatBoost yang
#   berjalan multi-thread TIDAK menjamin hasil bit-identik antar eksekusi,
#   karena urutan reduksi paralel saat pembentukan histogram bergantung pada
#   penjadwalan sistem operasi. Seed mengunci pengambilan sampel dan
#   inisialisasi, bukan urutan penjumlahan floating point.
#
#   Dampaknya terukur kecil: menjalankan ulang pipeline yang sama menghasilkan
#   selisih QWK sekitar 0,001 — jauh di bawah derau sampling leaderboard publik
#   (simpangan baku sekitar 0,009 pada 30% data uji). Struktur kesimpulan tidak
#   berubah.
#
#   Bagi yang membutuhkan hasil bit-identik, tambahkan deterministic=True dan
#   force_row_wise=True pada LightGBM serta setel n_jobs=1 pada seluruh model.
#   Waktu eksekusi akan meningkat beberapa kali lipat.
